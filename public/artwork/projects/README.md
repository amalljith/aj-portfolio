# Concept artwork

These four original, locally authored SVG compositions are fictional project
placeholders for AJ Portfolio, not screenshots or evidence of completed work.
They use the portfolio's graphite, ivory and orange palette. No stock images,
third-party artwork, scripts, external resources, filters or raster data are used.

Replace each `artwork` path and `artworkAlt` in `src/data/projects.js` when real
screenshots are supplied. Keep each project's ID stable for headings and motion.
The component reserves a 1000 by 700 image box; `object-fit: cover` handles other
source ratios. Inspect the desktop and mobile crop after replacement.
